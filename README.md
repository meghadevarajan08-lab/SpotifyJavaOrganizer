# Spotify Playlist Organizer

## Project Goal
A Java command-line tool that connects to the Spotify API to help users analyze, sort, and clean up cluttered playlists.

## MVP Scope (Minimum Viable Product)
- Authenticate securely with the Spotify Web API.
- Fetch user profile data and top tracks.
- Parse JSON track responses into Java objects.
- Display sorted track and artist data directly in the terminal.

## Future Plans & Schedule
- Add custom sorting filters (by genre, popularity, or audio features).
- Build a feature to automatically export sorted tracks into a new playlist.

## Tech Stack
- **Language:** Java
- **API:** Spotify Web API
- **HTTP Client:** Java `HttpClient`
- **Data Parser:** Gson / Jackson# SpotifyJavaOrganizer
